# Design Skill

## Design Philosophy
1. **Tool, Not Toy**: Build interfaces inspired by Linear, Raycast, and Obsidian. Dark-first, minimal borders, subtle glassmorphism, zero gimmicks.
2. **Iconography Standard**: Exclusively use MIT-licensed Lucide icons. Rendered as inline SVGs (`stroke-width="1.8"`, `viewBox="0 0 24 24"`, no emojis in core workflows).
3. **Palette & Scale**:
   - Backgrounds: `#090a0f` (App Base), `#11131a` (Card Base), `#181b24` (Elevated Surface).
   - Borders: `#222634` (Hairline), `#343a4e` (Hover/Active).
   - Accents: `#6366f1` (Indigo/Primary), `#10b981` (Emerald/Success), `#ef4444` (Rose/Danger), `#f59e0b` (Amber/Warning).
   - Typography: Clean system stack `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Inter, sans-serif`.
4. **Visual Hierarchy**: Data values take prominence over labels; interactive elements have visible focus states; progress indicators use high-precision metric badges.

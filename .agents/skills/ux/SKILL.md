# UX Skill

## Core Principles
1. **Zero-Click Detection**: As soon as a stream or video begins buffering, the extension detects and categorizes it immediately without requiring manual reloads.
2. **Non-Intrusive Floating Overlay**: In-video download pill only appears on video container hover, positioned at the top-right corner to never obstruct native player controls.
3. **Persistent Studio Lifecycle**: Streaming media downloads execute inside a dedicated browser tab or offscreen document so closing a popup or navigating the origin page never interrupts an active download.
4. **Immediate Feedback**: Clear progress bars, live transfer speed in MB/s, segment heatmaps, and in-studio preview player for audio/video verification.

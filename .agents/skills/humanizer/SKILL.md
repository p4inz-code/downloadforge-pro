# Humanizer Skill

## Purpose
Ensure all communication, code documentation, commit messages, and release notes read like they were crafted by a battle-hardened senior systems/web engineer.

## Principles
1. **Direct and Conversational**: State facts, tradeoffs, and decisions plainly.
2. **Zero Synthetic Fluff**: Ban generic transitional filler ("delve into", "testament to", "game-changer", "revolutionary").
3. **Engineering Grounding**: Anchor explanations in technical mechanisms: buffers, frame rates, memory bytes, sockets, and DOM nodes.
4. **Honest Critiques**: When something is broken or sub-optimal, say it clearly with the exact failure mode.
